# Plan 4: 広告 — AdMob 単体で 4 層モデル

作成日: 2026-09-12。設計書 §8（4 層モデル）・§9（ATT / UMP / プライバシーマニフェスト）・§3（モジュール分離）の実装計画と実施記録。
ユーザー不在時に作業者判断で実装した。**AdMob の本番 App ID / 広告ユニット ID はユーザーのアカウントが要るため、Google 公式のテスト ID を入れてある。**

## 決定（作業者判断。ユーザーの再決定で差し替えてよい）

1. **パッケージ分離**: 広告は `ios/ZutsuuAds`（別 Swift Package）に置き、ZutsuuKit（RiskEngine / PersonalRisk / KiabouUI / AppCore）に依存しない。
   逆にアプリ本体だけが両方に依存する。健康データ型へ広告側から型レベルで到達できない（設計書 §3）
2. **純粋ロジックと SDK を分ける**: `AdPolicy`（頻度制御・解放期限。macOS で `swift test` できる）と `ZutsuuAds`（Google Mobile Ads SDK + UMP のラッパー、iOS のみ）
3. **各層の置き場所**（Plan 3 でホームがダッシュボードになったため、設計書 §8.2 の「深掘り画面」を読み替える）

   | 層 | 置き場所 | 実装 |
   |---|---|---|
   | Tier 0 聖域 | 今日タブの above the fold（いまのリスク・次の通知・記録ボタン）、通知タップで開いた画面 | 広告を置かない |
   | Tier 1 インフィード | 今日タブの「時間別」リストの 6 行目の後に 1 枠（可視域に入ってからロード） | `NativeAdCard` |
   | Tier 2 インタースティシャル | タブ切り替えを「画面遷移」と数える。起動後の最初の遷移は除外、4 回ごと、前回から 3 分以上、1 日 6 回まで、通知経由の起動は数えない | `InterstitialGate` |
   | Tier 3 リワード | 「気圧との関係」（相関レポート）を広告視聴で 7 日間ひらく。地点追加・7 日先予報・グラフは機能自体が未実装なので未接続 | `RewardUnlocks` |
   | App Open | バックグラウンド復帰時のみ、前回表示から 4 時間以上、コールドスタートと通知経由は除外 | `AppOpenGate` |

4. **同意の順序**: UMP（GDPR/TCF）→ ATT → SDK 初期化。初期化はメイン画面の描画完了後に非同期（設計書 §8.3）。同意取得前・SDK 未初期化のあいだは全層とも何も出さない
5. **メディエーションなし**（設計書 §8.3。DAU が立ってから）
6. **プライバシー**: `NSUserTrackingUsageDescription` を 5 言語で用意。`SKAdNetworkItems` は Google の代表 1 件だけ入れてあり、**リリース前に Google 公式の全リストへ差し替える**。`PrivacyInfo.xcprivacy` はアプリ分のみ（SDK 各自のマニフェストは SDK に同梱）

## 実施記録（2026-09-12）

- `ios/ZutsuuAds`: `AdPolicy`（`InterstitialGate` / `AppOpenGate` / `RewardUnlocks`、テスト付き）と `ZutsuuAds`（`AdMobProvider`、`NativeAdCard`）
- アプリ: `AdsCoordinator` が方針と保存状態を持ち、RootView（遷移・復帰）、TodayView（インフィード）、KiabouTabView（リワード）、SettingsView（プライバシー設定の再表示）に接続
- Google Mobile Ads SDK 13.x / UMP 3.x を SPM で取得。テスト ID: App `ca-app-pub-3940256099942544~1458002511`
- **未検証**: 実端末での広告表示・同意フォーム（シミュレータはテスト広告が出るはずだが、UMP の地域判定と ATT は実機依存）。本番 ID への差し替えは `AdUnitIDs` の 1 箇所

## リリース前の宿題（ユーザー）

- AdMob で App ID と 4 種の広告ユニット（ネイティブ・インタースティシャル・リワード・App Open）を作り、`AdUnitIDs` と `GADApplicationIdentifier` を差し替える
- `SKAdNetworkItems` を Google の最新リストに差し替える
- UMP のプライバシーメッセージを AdMob 管理画面で作成する（作らないと EEA で同意フォームが出ない）
