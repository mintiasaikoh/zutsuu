# その人だけの空模様 — 追加アセット案

**検討用のラフ。色を自分で選ぶ方向はユーザー提案。個々のデザインと解放日数は案。**

体調の記録が増えると、相棒の色や模様、小物を本人が選べるようになる。
顔、体形、大きさは同じ。背中の淡い模様と、周囲の布小物で個性を作る。
本人の好みで組み合わせる。同じ記録日数でも異なる外観になる。

| 外観候補 | 体の模様・色 | 追加小物 |
| --- | --- | --- |
| いつもの | 原型の青い背中と白いお腹 | 生成済みの枕・青い毛布 |
| かすみ | 背中からヒレへ続く、幅の広い霞の帯 | 雲形の薄灰色の枕、霞色の毛布 |
| しずく | 灰みのある青緑、背中に大きな雫の模様を2つ | 雫形のクッション、青緑の毛布 |
| こもれび | 薄い砂色とセージ色が重なる、大きな柔らかい色面 | 砂色の枕、縁だけ淡緑の毛布 |

## 記録と着せ替えのつながり

ユーザーから「記録が増えると、色などを自分で選んで変えられるとモチベーションになる」
という提案があったため、学習結果で自動変化する案から、本人が選ぶ着せ替えへ変更する。

| 累計の記録日数（案） | 選べるもの |
| --- | --- |
| 最初から | 原型の青、無地背景、明るさ・ゆらぎ停止 |
| 3日 | かすみ色・しずく色・こもれび色 |
| 7日 | 霞の帯・雫・木漏れ日の模様 |
| 14日 | 雲形や雫形の枕、色違いの毛布 |

- 「良い」「悪い」は同じ1日分。未入力を「良い」と解釈しない。
- 連続日数ではなく累計日数。休んでも取り上げたり初期化したりしない。
- 同じ日の複数入力・訂正は、着せ替えの進捗では1日分。
  体調記録そのものの保存仕様とは分ける。
- 記録成功時だけ進捗を反映する。保存失敗や連打で増えないようにする。
- 選んだ姿は本人が変更するまで維持。既に選べるものはいつでも着替えられる。
- 背景の無地化・明るさ・停止操作など、快適さの設定に解放条件を付けない。
- 次の候補は「あと2日の記録で、しずく色が選べます」など短く表示する。
  派手な演出や、記録を迫る通知は加えない。

通知の個人化には、同じ体調記録を別の学習処理で利用する。
**着せ替えの解放と、通知の学習が十分になったことは同一ではない。**
たとえば3日で新しい色が選べても「あなたの傾向が分かりました」とは表示しない。
模様から病名や症状の重さを推定させる分類もしない。

## 素材の分け方

1. **体:** 共通のメッシュ・骨格に、原型＋3種類の色・模様を差し替える。
2. **小物:** 枕と毛布を別メッシュにし、体の模様に合わせて配色を変える。
3. **背景:** 既存の静かな入り江を共有。背景まで同時に進化させず、無地を選べる。

目と口には模様を載せない。細かな反復模様・光沢・点滅を増やさない。
1/fの揺れ幅は個人化の進み具合で増やさず、停止設定を維持する。

最初に制作するなら「かすみの体模様＋雲形の枕」の1組。
色差だけでなく輪郭でも違いを確認でき、原型の顔を変更せずに試せる。
