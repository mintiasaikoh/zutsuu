# きあぼう

気圧＋マンボウから、ユーザーが選んだ名前。
空をのんびり泳いで気圧の変化を知らせる相棒というコンセプト。
承認されたラフは`concept.png`。

丸く薄い体、青い背中、白いお腹、上下の大きなヒレ、短く波打つ後端を再現。
顔は小さな黒い目と口の線だけにし、瞳の光沢や唇の立体を付けない。

## 選べる背景と明るさ

`scenery.js` / `scenery.css`で「入り江・無地」と「やわらかい昼・薄明かり」を切り替える。
背景は静止画で、1/fの動きはきあぼうのビューアだけに適用する。
文字とボタンは背景画像の外に置き、薄明かりでは文字色も切り替える。
明るさ設定はこの画面だけに適用し、端末の画面輝度は変更しない。
見え方は専用のlocalStorageキーに保存し、休みの状態には干渉しない。
これは見た目の試作であり、症状の軽減効果を検証したものではない。

## 一緒に休む試作

「いまは、休む」で、きあぼうが毛布にくるまった寝姿になる。
本人の操作で休む状態になり、気圧から体調を自動判定しない。
個人で使う気圧アプリの相棒とし、交流や共有は機能に含めない。

`fluctuation.js`で、0.025–0.4 Hzの帯域に限った1/fゆらぎを合成する。
対数周波数に等パワーで96成分を配置し、ランダム位相と周波数のずれを与える。
左右・上下・姿勢へ独立した波を使い、ヒレの再生速度も緩やかに変える。
休む姿は振幅を通常の30%にする。固定の短いループにはしない。
「ゆらぎを止める」とページ非表示時には停止する。
動きを減らす設定が有効な場合は停止状態で開き、「ゆらぎを動かす」で明示的に再生できる。
再開時は停止した時点から続け、経過した実時間の分を飛ばさない。
ゆらぎはブラウザ側の表現で、配布GLB/USDZには焼き込んでいない。
参考: [model-viewerの姿勢指定](https://modelviewer.dev/examples/scenegraph/)、
[1/fパワースペクトルの原論文](https://www.nature.com/articles/258317a0)。

状態はこのブラウザの localStorage に保存する。再読込でも休んだ姿が残り、
「休みを終える」で次の休みを始められる。保存できない環境では画面内のみで動作する。
気圧予報との連動、iOSアプリ画面への組み込みは未実施。

寝姿を再生成するコマンド:

```bash
blender --background --python assets/kiabou/create_rest.py
```

## 構造と動作

- 7,864頂点、15,680三角形、4マテリアル、1メッシュ。
- 10本の骨、配色用の同梱テクスチャ1枚。
- `Drift`は6秒・30fps。上下のヒレ、胸びれ、後端、浮遊、まばたき。
- 大きなヒレは体・付け根・先端に重みを分けて曲げる。
- 書き出しはY-up。全高は約27cm。照明・床・カメラは素材に含めない。
- ループ端の連続性、体の上下動、上下のヒレの動作、GLBとUSDZの骨格アニメーションを検査。

動作はデモ。気圧データとの連動、アプリ画面への組み込み、iPhone実機検証は未実施。
アプリのリソースへUSDZを追加して読み込み、`Drift`をループ再生する想定。

## 再生成

リポジトリ直下から実行すると、このフォルダの生成済みモデルと確認画像を上書きする。

```bash
blender --background --factory-startup --python assets/kiabou/create_kiabou.py
blender --background --python assets/kiabou/export_kiabou.py
python3 -m http.server 8767 --bind 127.0.0.1 --directory assets/kiabou
```

プレビュー: `http://127.0.0.1:8767/`。
HTMLを直接開くとブラウザがモデルの読込を制限する場合があるため、上記サーバーを使う。
ビューア本体はCDNから取得する。モデルと配色テクスチャはローカルに同梱。
